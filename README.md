## 🎯 核心理念

> **“用 AI 赋能测试开发，用测试思维评估 AI。”**

本项目围绕测试开发场景，构建一个本地化、可演进、可自控的 AI 辅助工作台。核心理念分为三个层面：

| 维度 | 描述 |
| :--- | :--- |
| **正向赋能** | 利用大语言模型辅助生成测试用例、自动化脚本、Mock 数据，降低重复性编码成本，让测试人员聚焦高价值的场景设计。 |
| **逆向评估** | 对 AI 生成的内容进行质量评估，包括可用率、可执行率、幻觉率等指标，形成客观的反馈机制，代替“凭感觉判断好坏”。 |
| **持续演进** | 通过 RAG 知识库注入业务规则，通过评估数据指导 Prompt 优化，构建“生成 → 评估 → 优化”的工程闭环。 |

## ✨ 核心功能

- 💬 **智能对话**：多轮上下文对话，支持模型热切换
- 📋 **测试用例生成**：输入需求，输出结构化用例表格
- 🧪 **Pytest 代码生成**：输入描述，输出可执行的参数化测试代码
- 🎭 **Mock 数据生成**：输入字段，输出多场景 JSON Mock 数据
- 📚 **RAG 知识库**：接入业务文档，增强生成质量
- 📊 **质量监控**：核心指标可视化看板

## 🏗️ 整体架构

```
前端层（Web UI）
    对话界面    用例生成    代码生成    监控看板
                    ↓
服务层（Flask 后端）
    API路由     会话管理    模板管理    日志记录
                    ↓
AI 引擎层
    Ollama推理   RAG检索    质量评估
                    ↓
数据层
    模型文件     业务文档    向量数据库
```

### 各层职责

| 层级 | 职责 | 核心组件 |
| :--- | :--- | :--- |
| **前端层** | 用户交互界面，展示功能入口和结果输出 | 对话界面、功能面板、监控看板 |
| **服务层** | 处理 HTTP 请求，路由分发，会话保持，日志记录 | Flask 路由、Prompt 模板管理、Session 管理 |
| **AI 引擎层** | 大模型推理、知识库检索、质量评估 | Ollama 客户端、RAG 引擎、Evaluator |
| **数据层** | 模型文件存储、业务文档存储、向量持久化 | GGUF 模型文件、Markdown/JSON 文档、ChromaDB |

## 🔧 技术选型

| 组件 | 选型 | 说明 |
| :--- | :--- | :--- |
| 后端 | Flask 3.0 | 轻量 Web 框架 |
| AI 推理 | Ollama + CodeLlama-7B (Q4_K_M) | 本地运行，3.8GB |
| 向量库 | ChromaDB | 轻量本地向量库 |
| 嵌入模型 | all-MiniLM-L6-v2 | 80MB，CPU 可运行 |
| 前端 | 原生 HTML + CSS + JS | 无框架依赖 |

## 💻 系统要求

- CPU：4 核及以上
- 内存：8 GB 以上（推荐 16 GB）
- 显存：6 GB 以上（推荐 8 GB）
- 存储：20 GB 以上可用空间
- Python 3.11+ + Ollama 最新版
